# 92K 情绪周期决策台（92K System）

面向 A 股短线的**龙头 / 补涨 / 切换 情绪周期量化决策辅助网站**，按「92 策略体系」需求表（数据层 / 计算层 / 展示层 / 架构）实现。
定位是**决策辅助工具**，不是自动交易系统——能量化的硬数据全部量化，题材判断等主观部分提供辅助信息，最终由人决策。

> ⚠️ 免责：**默认 `DATA_SOURCE=real` 实盘模式**——行情来自**新浪+腾讯多备份数据源**（快速批量实时
> 按延迟择优/故障自动切换；成分与行业来自新浪，日K 新浪主/腾讯备），可能存在延迟或误差，
> **不构成投资建议**。也可用 `DATA_SOURCE=mock` 离线演示（内置确定性模拟市场）。
> 回测基于“成交额前 N 只(默认500)实时样本”的真实历史，情绪判定按样本折算全市场口径；
> 新闻/公告接口尚未接入（对应条件中性处理）。系统对主观题材的评分(如“逻辑硬”关键词近似)必须人工复核。
>
> 前端使用**相对地址**（资源 `./assets/...`、API `./api/...`），可部署在站点根路径或经反向代理映射到任意前缀。

## 一、快速启动

环境要求：Python 3.10+、Node.js 18+（仅前端构建需要）；实盘模式要求**能访问新浪财经接口**。

```bash
# 1) 后端依赖
py -m pip install -r requirements.txt

# 2) 前端（首次；仓库已内置构建产物 backend/app/static，改动页面才需重建）
cd frontend
pnpm install          # 或 npm install
pnpm build            # 产物输出到 backend/app/static
cd ..

# 3) 启动（默认实盘: 启动时自动拉取全市场快照→行业映射→成交额前500样本日K回填(首次约1-3分钟,以后秒级跳过)）
py run.py
# Windows 也可直接双击 run.bat
```

打开浏览器访问 **http://127.0.0.1:8720**（端口可用环境变量 KB_PORT 修改）。API 文档: http://127.0.0.1:8720/docs

> 想离线演示可 `set DATA_SOURCE=mock` 后重启（另建 mock 库, 内置2.1年确定性行情剧本）。
> `.env.example` 列出全部可调参数（轮询间隔/样本数量/回填天数等）。

## 二、功能与需求对照

| 页面 | 对应需求 | 说明 |
| --- | --- | --- |
| 首页/仪表盘 | U-01 情绪仪表盘、C-01 情绪周期、C-06 仓位建议、D-02 涨跌停统计 | 阶段判定+置信度+依据；**全市场实时** 涨停/跌停/涨跌家数/最高连板/溢价/炸板/成交额；**量能卡(今日 vs 昨日同时段, 上证5min口径, 次日升级为全市场档案口径)**；**情绪周期分段时间轴**(同色段=同一阶段, 悬停看统计)；**板块强弱榜可展开**(今日涨停股自动分层: 龙头/高标断板提示/补涨首板/跟风, 及量能列)；盘中实时异动榜 |
| 龙头榜 | U-02、C-02（L-01..L-06 六维评分） | 市场总龙/板块龙(真实行情)、条件逐条、龙头历史时间线、总龙K线(真实日K)、禁忌提示 |
| 股票池 | U-03 补涨池、U-04 切换池、C-03/C-04（B/S 条件评分） | 规则触发说明、逐条入选理由、首板/一进二买点标记(真实涨停与连板) |
| 个股分析 | U-07、C-05 买卖信号 | 近300根真实日K(前复权)+量能+均线、龙头/补涨/切换三套条件、信号与理由 |
| 信号看板 | U-05 | 全部买入/卖出/观察信号+理由，按方向/策略过滤 |
| 打板操作台 | 打板全流程台账 | 92模式自动盯盘：龙头/补涨买点→**买入池**；卖点(止损/断板/加速一致/不及预期)→自动结算进**卖出池**（买入时间价、卖出时间价、盈亏%、买卖理由）；符合模式候选进**观察池**（记录日期与理由）；最新买卖点提示流每8s推送；手动了结/忽略/手动加观察 |
| 回测中心 | U-06、C-05 | 自动/龙头/补涨/切换模式，基于样本池(成交额前500, 真实前复权日K)逐日回放 |
| 管理/运维 | T-04 | 交易时段全市场轮询(约8s)、盘后日K自动回填、`/api/admin/status`、数据源自检 |

情绪周期：主跌阶段 → 低位震荡(试错期) → 主升阶段 → 高位震荡，阈值表+状态机引擎按
`连续跌停家数 / 昨日涨停溢价 / 连板高度与梯队 / 龙头断板 / 中位股亏钱` 等硬指标判定并给出置信度（历史部分按样本折算全市场口径）。

## 三、目录结构

```
92KeBi/
├─ backend/app/
│  ├─ config.py           # 环境变量/规则阈值(REAL_RULE 全市场 / RULE 模拟刻度)/仓位映射
│  ├─ db.py               # SQLite 存储(mock 与 real 各自独立库文件)；生产换 MySQL 仅替换实现
│  ├─ providers/          # 多源行情: sina(行情中心/hq/日K) tencent(qt批量实时/前复权日K)
│  │                      #            router(健康度+延迟择优+故障自动切换)
│  ├─ real/               # 实盘运行时: market(快速双源tick+周期全量同步/涨跌停/连板/溢价/行业)
│  │                      #            sample(样本池挑选 + 真实日K回填)
│  │                      #            analyze_real(情绪/龙头/池/信号编排, 样本折算全市场)
│  ├─ seed/               # mock 专用确定性模拟市场(离线演示)
│  ├─ core/               # 刻度无关引擎: board / phase / leaders / pools / signals / risk
│  │                      #   + backtest(稠密数组加速, 500只×2年约10s)
│  ├─ market_cache.py     # 视图缓存（自动分派 mock/real）
│  ├─ api/                # REST 路由（routes 展示类 / extra 个股·回测·管理）
│  ├─ tasks/scheduler.py  # 实盘轮询(交易时段8s/非交易10min) + 盘后日K回填 + 复盘
│  ├─ static/             # 前端构建产物（pnpm build 生成）
│  └─ main.py             # FastAPI 入口(lifespan 按模式初始化)
├─ frontend/              # React 18 + Vite + ECharts5（src/pages 各功能页）
├─ docs/snap/*.json       # API 响应快照（开发契约样例）
├─ run.py / run.bat       # 启动
└─ data/                  # 运行时: market_real.sqlite3 / market.sqlite3 / 行业缓存(自动生成)
```

## 四、实盘口径与 API 速览

- `GET /api/dashboard/overview` 首页聚合（stats=全市场实时，含 volume 量能对比）
- `GET /api/market/sector-zt?sector=板块名` 板块内今日涨停股+龙头/补涨/跟风分层
- `GET /api/ops/overview` 打板台账（提示流/买入池/卖出池/观察池/统计）
- `POST /api/ops/flush` 立即自动扫描一次（买点/卖点/观察池）
- `POST /api/ops/manual-sell?code=` 手动了结持仓 | `manual-watch` 手动加观察 | `ignore` 移除
- `GET /api/dashboard/sectors` 全板块(含 vol_ratio 量能列, 需次日档案积累)
- `GET /api/leaders` 龙头 | `/api/pools` 股票池 | `/api/signals` 信号 | `/api/stocks/{code}` 个股(任意代码, 按需拉真实K线)
- `POST /api/backtest/run` 回测（样本池真实日K） | `GET /api/backtest/meta` 样本说明
- `POST /api/admin/refresh` 强制刷新快照与分析 | `GET /api/admin/status` 状态(轮询/回填进度/快照时间)
- `POST /api/admin/probe-sina` 新浪源连通性自检 | `POST /api/admin/advance` 仅 mock 可用
- 说明：情绪历史/回测基于“当日成交额前 `REAL_CRAWL_N`(默认500)只”样本并**按密度折算全市场口径**展示；
  当日涨停/跌停/涨跌家数等大盘指标为**全市场实时精确值**；新闻/公告接口未接入（对应条件中性，需人工复核题材）。

## 五、Roadmap / 可调项

1. 提高覆盖面：`REAL_CRAWL_N=1200~2000`（样本越接近全市场，回填与回测越慢，需按网络调 `REAL_CRAWL_CONCURRENCY`）；
2. 接入新闻/舆情（东财/新浪搜索等写入 `news` 表），恢复 S-05 新闻驱动与题材热度贡献；
3. 阈值校准：情绪引擎阈值在 `config.py` `REAL_RULE`，可结合自己复盘再调；
4. 生产部署：`uvicorn app.main:app --host 0.0.0.0 --port 8720`，`db.py` 换 ORM+MySQL 保留表结构；
5. 可用 `DATA_SOURCE=mock` 离线回归（引擎刻度无关、两套阈值同源）。
